# 🏦 Bank Loan Analysis Dashboard

An interactive **Bank Loan Analysis Dashboard** built using **Python and Streamlit** to analyze loan application data and generate meaningful insights through data visualization.

## 📌 Project Overview

The objective of this project is to analyze bank loan data and understand customer behavior, loan approval patterns, income distribution, and other important factors affecting loan applications.

The dashboard provides an interactive interface where users can filter data and explore different aspects of loan information.

---

## 🚀 Features

- 📊 Key Performance Indicators (KPIs)
  - Total Loan Applications
  - Average Income
  - Average Loan Amount
  - Approval Rate

- 📋 Dataset Overview
  - Total records
  - Total features
  - Missing values

- 🔍 Interactive Filters
  - Loan Status
  - Customer Gender

- 📈 Data Visualizations
  - Loan Status Analysis
  - Loan Amount Distribution
  - Income vs Loan Amount
  - Customer Analysis

- 👥 Customer Insights
  - Gender-wise analysis
  - Education-wise analysis
  - Loan purpose analysis
  - Home ownership analysis

- 📋 Statistical Summary

## ⚙️ Installation & Setup

Clone the repository:
```bash

git clone <repository-link>

cd Bank-Loan-Analysis-Dashboard

python -m venv .venv

For Windows:

.venv\Scripts\activate

Install required dependencies:

pip install -r requirement.txt

Run the Streamlit application:

streamlit run app.py

The dashboard will open in your browser at:

http://localhost:8501
